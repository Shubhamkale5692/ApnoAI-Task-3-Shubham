## 📋 Project Overview

**PULSE FITNESS** is a professional fitness center and athletic training studio web application crafted to deliver an engaging, cinematic, and interactive user experience. Designed with a striking neon green, deep black, and crisp white aesthetic, the website highlights modern web design standards—combining smooth scroll interactions, real-time 3D equipment rendering, dark/light theme switching, and comprehensive fitness business features.

---

## 🎯 Project Purpose

This project was built as part of the **ApnoAI "Project First Client — Real Business Website"** task. The objective was to design and engineer a production-ready, client-grade website tailored for a fitness business, delivering excellence in responsive layout architecture, modern UI/UX design, interactive frontend engineering, and clean code standards.

---

## ✨ Features

- **Responsive Design:** Fluid and adaptive layout optimized across mobile phones, tablets, laptops, and ultra-wide desktop monitors.
- **Interactive 3D Fitness Animation:** Real-time 3D dumbbell and fitness equipment scene powered by Three.js with mouse-follow parallax, dynamic lighting, neon energy rings, and particle effects.
- **Dark and Light Mode Toggle:** Seamless theme switcher with persistent user preference storage (`localStorage`) and smooth visual transitions.
- **Smooth Scroll Animations:** Intersection Observer-driven fade, slide, and zoom entrance effects paired with smooth in-page navigation.
- **Fitness Programs Section:** Dedicated workout catalog (Strength & Conditioning, HIIT & Cardio, Functional Training, Personalized Coaching) with interactive 3D card tilt and glowing hover states.
- **Membership Plans with Pricing Toggle:** Transparent tier comparison (Basic, Pro, Elite) featuring an interactive monthly vs. annual billing toggle.
- **Trainer Profiles:** Certified coach and personal trainer showcase with bios, specializations, social links, and 3D hover effects.
- **Photo Gallery with Filtering & Lightbox:** Categorized visual gallery with tabbed category filtering and a full-screen interactive modal lightbox.
- **Testimonials Slider:** Interactive slider showcasing client reviews, transformation stories, and star ratings with touch/click navigation.
- **Contact Form with Validation:** Complete inquiry form featuring client-side input validation, floating label effects, and direct integration with EmailJS.
- **WhatsApp Contact Button:** Floating quick-access WhatsApp chat trigger for immediate client communication and onboarding inquiries.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic markup structure adhering to modern web accessibility standards.
- **CSS3:** Custom CSS architecture leveraging CSS Custom Properties (Variables), Flexbox, CSS Grid, 3D transforms, keyframe animations, and responsive media queries.
- **JavaScript (ES6+):** Pure vanilla JavaScript driving DOM interactions, modal lightboxes, sliders, form validation, and theme state management without external heavy frameworks.
- **Three.js (r128):** WebGL-powered 3D graphics library rendering the real-time hero dumbbell, neon energy rings, ambient scene lighting, and glowing particles.
- **EmailJS Browser SDK:** Browser-side email dispatch integration for the contact form.
- **Font Awesome 6:** Vector iconography for user interface elements and social media channels.
- **Google Fonts:** Typography pairing using *Outfit* (bold display heading font) and *Plus Jakarta Sans* (sleek body font).
